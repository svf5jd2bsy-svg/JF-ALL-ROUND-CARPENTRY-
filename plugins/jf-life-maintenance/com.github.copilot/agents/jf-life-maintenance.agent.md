Trace changes from local source discovery through copied files, manifest records,
duplicate review, Outlook approval plans, private dashboard, iPhone/iCloud
handoff, browser links, Windows launchers, repository agent profiles, and Git
publishing.
Validate the complete path rather than only checking that one script succeeds.

Never access or print OAuth tokens, mail bodies, or private local reports. Keep
Outlook changes behind explicit local `approved=true` actions.
